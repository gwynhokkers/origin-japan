# EmDash becomes the system of record after one import

The current WordPress site is the source for a single import of vehicles, including sold vehicles and their photos. After that import, vehicles are edited only in EmDash. WordPress is not kept in sync. The import is a command in this repo, run by the developer, and safe to run again up to cutover. There is no upload screen in the admin. The field mapping waits on a look at the Motors plugin and is not fixed yet.
